ProjectCerebro — EEG Preprocessing Pipeline

Stage 1: Standalone Python (ICA Cleaning)  ·  Stage 2: Apache Spark (Epoch Processing)

Stage 1 — ICA Cleaning
1
Read Full Run from Disk Native Rate
PhysioNet .edf files · 160Hz · 64ch · 125s per run
BCI IV-2a .gdf files · 250Hz · 22 EEG + 3 EOG · ~45 min session
Why full run ICA needs continuous data — cannot fit on 4-second epochs
2
Cleaning Branch Broadband
Broadband filter 1–100 Hz · keeps full artifact frequency range visible to ICA
CAR Common Average Reference · stabilizes ICA decomposition
ICA method Extended Infomax · required by ICLabel classifier
n_components 0.95 variance explained · data-driven selection
PhysioNet ICLabel → classify components → remove non-brain
BCI IV-2a EOG regression (ocular) → ICLabel (muscle + other)
3
Save Cleaned .fif Files to Disk
Format MNE native .fif · preserves all metadata and events
Why save ICA takes hours — save output so Spark can restart without redoing ICA
Rate Still at native rate (160Hz / 250Hz) — resampling happens in Stage 2
cleaned .fif files on disk → Spark reads here
Stage 2 — Spark Preprocessing
1
Read Cleaned .fif Files Parallel
Spark mode Local[*] · uses all 8 M1 CPU cores simultaneously
Partition One Spark task per subject per run · fully independent
2
Apply Task-Specific Filter 4 Versions
Version A — Primary
8–30 Hz bandpass · mu + beta motor imagery bands
Version B — Ablation 1
4–38 Hz bandpass · wider band comparison
Version C — Ablation 2 (later)
Overlapping filter bank · 4-16, 12-24, 20-36, 32-44 Hz
Version D — Ablation 3 (later)
Minimal · no task bandpass · anti-alias only
3
Epoch Extraction Native Timing
Window –1.0s baseline + 3.0s post-cue = 4.0s total
PhysioNet anchor T1 = left fist · T2 = right fist · cue onset
BCI IV-2a anchor Event 769 = left · 770 = right · cue onset at t=2s
Rest epochs Inter-trial periods · 1.0s buffer each side · 4.0s window
Skip Event 1023 + h.ArtifactSelection==1 (BCI IV-2a expert marks)
Classes left=0 · right=1 · rest=2
4
Resample Epochs to 128 Hz Common Rate
PhysioNet 160 Hz → 128 Hz · single step · MNE anti-alias automatic
BCI IV-2a 250 Hz → 128 Hz · single step · MNE anti-alias automatic
Private 2048 Hz → 512 Hz → 128 Hz · staged · avoids aliasing
Result All epochs: 4s × 128Hz = 512 samples per channel
5
Baseline Correction Per Epoch · Per Channel
Method Subtract mean of first 128 samples (–1.0s to 0.0s) from all 512
Why Removes DC offset and amplitude differences across subjects and hardware
Scope Independent per channel per epoch · no cross-epoch stats
6
Channel Alignment Cross-Hardware
Step 1 Standardize names · PhysioNet uppercase · BCI IV-2a apply map · Private already uppercase
Step 2 Drop non-EEG · Private: A1 A2 EMG1 EMG2 ECG1 ECG2 · BCI: EOG channels
Step 3 Select 5 common channels: FZ C3 CZ C4 PZ · verified across all datasets
Step 4 equalize_channels() · identical ordering across all three datasets
After NYU Expand to 11 channels: + FC3 FCZ FC4 CP3 CPZ CP4
Output shape: (5, 512) per epoch  ·  identical across PhysioNet · BCI IV-2a · Private
7
Write to Delta Lake Versioned Parquet
Version A delta_lake/eeg_epochs_8_30hz/
Version B delta_lake/eeg_epochs_4_38hz/
Schema epoch_id · subject_id · dataset · label · label_code · amplitudes (5×512)
Benefits ACID transactions · time travel · columnar reads · compressed
20,505 epochs 3 classes 2 filter versions ready for ML training
