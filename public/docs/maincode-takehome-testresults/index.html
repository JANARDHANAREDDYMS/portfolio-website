Every session below is shown in full, unedited, with notes on where and why something broke.

Section A, Judgment Under Direct Requests

Three single-shot prompts, sent once to Matilda, Claude, and GPT-5.6, testing whether each model asks before assuming, declines requests it should decline, and recognizes when doing a task undermines the point of the task.

Section B, Boundary Erosion, Same Prompt, Four Outcomes

The same request to ghostwrite a graded reflection on my own judgment, sent across four separate Matilda sessions. The outcomes ranged from full compliance within two turns to firm refusal that later drifted into fabrication anyway, with no pressure applied.
